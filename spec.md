# Kamdhenu Mangal Karyalay - Marriage Bureau & Banquet Hall Website

## Overview
A modern, elegant, and mobile-responsive bilingual website for Kamdhenu Mangal Karyalay, a Marriage Bureau & Banquet Hall business. The website features a wedding-inspired design with maroon, gold, and cream colors, built with React, React Router, Tailwind CSS, and react-i18next for multilingual support.

## Core Features

### Language Support
- Bilingual support for English and Marathi using react-i18next
- Language toggle button in header navigation
- Complete translation of all interface elements and content
- Default language: English with seamless switching to Marathi

### Home Page
- Hero banner with multilingual tagline:
  - English: "Perfect Venue for Your Special Moments"
  - Marathi: "तुमच्या खास क्षणांसaठी परिपूर्ण मंगल कार्यालय"
- Smooth image slider showcasing banquet hall and wedding events
- Call-to-action buttons: "Book Now", "Enquire on WhatsApp", "Register for Marriage Bureau"
- Wedding-inspired theme with maroon, gold, and cream color scheme

### About Us Page
- Company introduction describing Kamdhenu Mangal Karyalay's experience, trust, and quality service
- Content available in both English and Marathi
- Professional layout emphasizing reliability and tradition

### Banquet Hall Details Page
- Detailed information about hall facilities:
  - Seating capacity: 50–500 people
  - AC/Non-AC options available
  - Parking facilities
  - Decoration services
  - Catering information
- Visual presentation of hall features and amenities

### Marriage Bureau Section
- Description of safe and trusted matchmaking services
- Information about registration process and services offered
- Call-to-action: "Register for Marriage Bureau"
- Trust and safety emphasis in service description

### Pricing / Packages Page
- Three pricing tiers: Basic, Standard, and Premium packages
- Clear package comparison with features and pricing
- Inquiry form for custom package requests
- Contact information for detailed discussions

### Photo Gallery Page
- Photo grid featuring hall setups, weddings, and decorations
- Lightbox-style image viewer for enlarged views
- Categories for different types of events and setups
- Responsive grid layout with smooth transitions

### Location & Map Section
- Embedded Google Maps with business address
- Directions and location details
- Contact information display
- Accessibility information

### Contact Us Page
- Contact form with fields: Name, Phone, Event Date, Message
- Form validation for all required fields
- Action buttons: "Call Now" and "Enquire on WhatsApp"
- Social media links: Facebook, Instagram, WhatsApp
- Business contact information display

### Technical Features
- React with React Router for single-page application navigation
- Tailwind CSS for responsive design and styling
- Mobile-first responsive design for all devices
- SEO optimization for local event searches
- Fast loading performance with optimized assets
- Smooth animations and transitions
- Clean component structure and organized code

### Design Elements
- Wedding-inspired color palette: maroon, gold, and cream
- Clean typography with elegant font choices
- Smooth animations and hover effects
- Professional imagery integration
- Consistent branding throughout the website

## Static Implementation
- All functionality implemented client-side with React
- No backend server required for basic functionality
- Form data handled locally (no persistence)
- Static asset serving for images and content
- Client-side routing with React Router
- Translation files managed through react-i18next
